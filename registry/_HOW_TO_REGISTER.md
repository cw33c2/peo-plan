# 📋 新技能入職說明書 (How to Register a New Skill)

## 當老闆完成一個新技能，請這樣跟 peo-plan 說：

```
peo-plan，我做了一個新技能，請幫我登記入職：
- 名稱：[skill-name]
- 功能：[它能做什麼，2-3句話]
- 安裝位置：[本機路徑 or GitHub URL]
- 觸發方式：[怎麼呼叫它，例如：在對話輸入 /skill-name 即可觸發]
```

## peo-plan 收到後會做什麼：
1. 在 `registry/[skill-name].md` 建立一張標準入職卡。
2. 把這個技能加入總覽表（SKILL.md 第四部分）。
3. 未來有符合的任務進來，peo-plan 會自動調度它。

## 入職卡標準格式：
```markdown
# [技能名稱]
**觸發時機**：[什麼情況下該呼叫這個技能]
**能力摘要**：[最多 3 行，說清楚它能做什麼]
**無法處理**：[明確列出它做不了什麼]
**安裝位置**：[本機路徑或 GitHub URL]
**傳達方式**：[要怎麼跟它說話，例如直接在對話輸入 /xxx]
```

# fal-ai-mcp-server — AI 生圖 & 影片菜商
**觸發時機**：需要生成 AI 圖片或 AI 影片時。包含設計稿需要佔位圖、老闆要生成作品圖、或任何需要「憑空生出視覺素材」的任務。
**能力摘要**：
- 支援圖片模型：Flux.1 Dev / Flux 1.1 Pro / DALL-E / Stable Diffusion 3.5
- 支援影片模型：Kling AI Pro / HunyuanVideo / Wan-I2V Turbo
- 支援圖片編輯（Gemini Flash Edit）
**無法處理**：影片剪接、字幕加工、已有圖片的後製（需搭配其他工具）。
**安裝位置**：`C:\Users\ASUS\.gemini\config\skills\fal-ai-mcp-server\SKILL.md`
**傳達方式**：直接對 AI 說「請用 Fal.ai 生成一張 [描述] 的圖片」即可自動調度。
